# Настройки

`config init` создаёт раскладку настроек в `~/.tt-testops/`:

```
~/.tt-testops/
  config.json                       общий файл: текущий профиль
  skills-registry.json              реестр установленных копий скилла
  profiles/
    default/
      profile.json                  настройки контура, без секретов
      credentials.json               секреты, права 0600 на POSIX
      cache/                        локальное хранилище профиля
```

Впишите адрес сервера и словари в `profiles/default/profile.json`:

```json
{
  "description": "<контур>",
  "servers": {
    "testops": {
      "kind": "allure-testops",
      "baseUrl": "https://<сервер>"
    }
  },
  "defaultProject": 100,
  "projects": { "100": "WEB", "200": "<имя>" },
  "trees": { "100": "<название дерева>", "200": "none" },
  "people": { "user01": "Иван Иванов" }
}
```

Токен — в `profiles/default/credentials.json`:

```json
{
  "testops": { "token": "<токен>" }
}
```

> [!NOTE]
> `~/.tt-testops/` уже вне репозитория — файлы там не попадают в git ни при каких условиях.
> Токен берётся в TestOps: профиль → API tokens.

Проверить, что подхватилось: `tt-testops config`. Каждое поле показано со значением и источником
(`flag`, `env`, `file`, `default`); секрет `testops.token` — только признаком «задан» или «не задан»,
само значение команда не печатает никогда.

**Выбор профиля**, первый сработавший источник: флаг `--config <путь к profile.json>` → флаг
`--profile <профиль>` → переменная `TT_TESTOPS_PROFILE` → поле `profile` общего файла `config.json` →
`default`. Значение каждого поля берётся в порядке: флаг команды, если у поля он есть, → переменная
окружения → файл `profile.json` → умолчание.

**Команда `config`**:

| Подкоманда | Что делает |
|---|---|
| `config` | текущий профиль, пути файлов, значение и источник каждого поля |
| `config --json` | то же структурой в стандартный вывод; диагностика — в поток ошибок |
| `config init [--profile <профиль>]` | создаёт общий файл, каталог профиля, `profile.json` и `credentials.json`; существующие файлы не трогает |
| `config use <профиль>` | переключает текущий профиль |
| `config profiles` | список профилей с описанием, текущий отмечен |

Коды возврата: `0` — успех; `1` — любая ошибка, включая ошибку настроек, с сообщением о причине.
Единого отдельного кода на ошибки настроек продукт не выделяет.
